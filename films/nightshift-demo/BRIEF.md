# Nightshift demo — BRIEF

## Product

Nightshift: an evidence-driven AI operations agent for stalled report-generation jobs in a controlled, application-owned environment. It investigates, chooses allowlisted repairs, acts within policy, and verifies the original artifact.

## Message

Unfinished report work is handled without inventing outcomes: evidence stays, leases are fenced, and success means artifact reconciliation.

## Length and format

- Delivery: 16:9, 1920×1080, 60 fps, with synthesized score (cinetic audio pipeline).
- Target cut: ~100 s UI walkthrough (cinetic default walkthrough is 20–90 s).
- Reason for length: neatHack demo video must cover architecture, runtime, and evidence for neatlogs, Entire, and cfo.ai within ≤3 minutes. This cut stays under that ceiling.
